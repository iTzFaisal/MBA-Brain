# Chapter 7: Social Media and Semantic Web Technology

## Core Idea
Web 2.0 changed the Web from an author-controlled publishing channel into a participatory platform where users create content, form communities, tag information, and talk back to organizations. Businesses gain advantage by listening and responding, being discoverable through search, using semantic context, and proactively recommending relevant content without losing sight of privacy, trust, and manipulation risks.

## Frameworks Introduced
- **Web 1.0 -> Web 2.0 -> Web 3.0 model**: Web 1.0 used static pages, author-controlled content, individual users, and influence-oriented marketing. Web 2.0 uses dynamic pages, user-generated content, communities, multiple data sources, and relationship-oriented marketing. Web 3.0 or the **Semantic Web** adds metadata, artificial intelligence, natural language processing, linked data, and computer-understandable meaning.
- **Web 2.0 social strategy**: Use **Listening** to monitor what customers say, **Talking** to communicate a message, **Energizing** to develop brand advocates, **Supporting** to provide service and peer help, and **Embracing** to solicit ideas and improvement suggestions. Treat this as a two-way operating discipline, not a posting calendar.
- **Web 2.0 application toolbox**: Select among social networking services, blogs and microblogs, sharing sites, mashups and RSS, social bookmarking and tags, wikis, e-commerce 2.0/social commerce, crowdsourcing, crowdfunding, collaboration platforms, and social monitoring services according to the business task.
- **Crawler search engine pipeline**: Use the sequence **crawler control module -> spiders -> page repository -> indexer/inverted index -> collection analysis module -> retrieval/ranking module -> query interface/SERP**. The indexer records terms and locations; ranking uses many proprietary relevance criteria. Enterprise search adds access control for internal structured and unstructured content.
- **Search marketing**: Use **search engine optimization (SEO)** to improve unpaid organic listings through relevant content, keywords, usability, mobile performance, and links. Use **search engine marketing (SEM)** or pay-per-click (PPC) advertising when paid visibility is needed, especially for a new or poorly ranked site. Track click-through rates, traffic, and purchases to estimate ROI.
- **Semantic Web and semantic search**: Add metadata and use NLP and AI to understand **context** (user intent), **personalization** (user characteristics), and **vertical search** (a domain such as travel, finance, legal, or medicine). W3C languages include **RDF**, **OWL**, and **SPARQL**. Use semantic page titles, keywords, and structured data to produce richer search listings and higher click-through rates.
- **Recommendation engines**: Use **content-based filtering** for item similarity, **collaborative filtering** for similarity among users, and **hybrid recommendation engines** to combine methods. Hybrid forms include **weighted**, **mixed**, **cascade**, and **compound** approaches. Check for cold start, sparsity, limited feature content, and overspecialization.

## Key Concepts
- **Web 2.0/social Web**: A Web phase characterized by dynamic pages, broadband, social media, mashups, and user-generated content.
- **User-generated content (UGC)**: Content created and shared by users rather than only by the site owner.
- **API/SDK**: Programming interfaces and development tools that let applications share data and functionality.
- **Content marketing**: Valuable, relevant, consistent content used to attract and retain an audience and drive profitable action.
- **Social commerce**: Social strategies and interactions used to influence purchasing behavior.
- **Social monitoring**: Tracking conversations, sentiment, influence, and brand activity across social services.
- **Search engine results page (SERP)**: The ranked page of results returned for a query.
- **Metadata/Natural Language Processing (NLP)**: Descriptions of data and technology for interacting with computers using ordinary language.
- **Semantic Web search**: Search based on meaning, relationships, context, and intent rather than only keyword matches.
- **Recommendation engine**: A system that predicts and proactively presents content, products, people, or services a user may value.

## Mental Models
- Move from **broadcast to conversation**: publish useful content, listen for response, support users, and let communities shape the message.
- Move from **active search to assisted discovery**: SEO helps a user find the firm; recommendations help the firm surface the next useful option.
- Move from **keywords to intent**: context, personalization, vertical domain, metadata, and relationships make information more relevant.

## Anti-patterns
- **Broadcast-only social marketing**: Posting promotions without listening or supporting customers ignores the defining value of Web 2.0.
- **Chasing vanity metrics**: Followers or impressions are not enough; connect activity to engagement, service, conversion, retention, or learning.
- **Treating SEO as keyword placement alone**: Search engines also evaluate experience, mobile display, content quality, links, and intent.
- **Exposing enterprise content without access control**: Enterprise search must balance discoverability with job function, clearance, and sensitive data.
- **Ignoring recommender limitations**: A new user, sparse ratings, weak product metadata, or overspecialized results can make personalization irrelevant.

## Worked Example
Songkick used Facebook Login so customers could create accounts without lengthy forms; about half of its customers used it. The Facebook SDK and App Events Export API supplied demographic, behavioral, engagement, and retention insight for personalized concert alerts. Facebook App Ads connected a Songkick ad to the relevant app page, while Deep Linking took a new installer directly to the Goo Goo Dolls event that prompted the download. Songkick reported 7% more purchases from Facebook Login users, a 15% sales increase from Analytics for Apps, and 35% higher lifetime value for customers acquired through Facebook. The example shows how APIs, identity, analytics, deep links, and relevant recommendations reinforce one another.

## Key Takeaways
1. Web 2.0 gives users control over content, relationships, tagging, and feedback; businesses must participate in the conversation.
2. Choose social tools by task: service, recruiting, collaboration, content, research, innovation, or commerce.
3. Use the search pipeline and access controls to make internal knowledge findable without making it indiscriminate.
4. Combine SEO and SEM, optimize for mobile and voice, and measure search ROI through behavior.
5. Semantic technologies improve relevance by interpreting meaning, context, relationships, and intent.
6. Recommendations create value when data quality, filtering method, diversity, privacy, and user trust are managed together.
