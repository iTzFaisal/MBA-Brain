# Change Judgment Cheatsheet

## Start Here

| If you see... | Do this first |
|---|---|
| A visible symptom and a favored solution | Separate **what** from **how**; diagnose before prescribing. |
| A changing market, regulation, technology, or social expectation | Run PESTEL and an Open Systems scan; translate signals into internal implications. |
| Weak performance with unclear cause | Map Nadler and Tushman's work, people, formal, and informal fit; repeat at the affected level. |
| A change that produces side effects or delayed results | Use Sterman's feedback, actor-response, lag, buffer, and multiple-goal test. |

## Change Path Decisions

| Phase | Judgment question | Default move |
|---|---|---|
| Awakening | Is the present state genuinely insufficient? | Triangulate external data, stakeholders, internal hard/soft data, and leader blind spots. |
| Mobilization | Do people see the gap, destination, and personal relevance? | Build readiness beliefs, a credible change vision, coalition, and participation. |
| Acceleration | Can the organization act while still operating? | Assign owners, resources, skills, milestones, contingencies, communication, and transition capacity. |
| Institutionalization | Has behavior become normal and effective? | Check outcomes, systems, measures, culture, and learning; then begin the next scan. |

The Change Path is a loop, not a rigid checklist. If new evidence changes the diagnosis, return to Awakening or Mobilization.

## Select the Route

- If the work is clear, structured, and predictable, use thinking first and a programmatic plan.
- If people must experience an integrated solution, use seeing first: prototype, pilot, demonstrate, and learn.
- If the situation is novel or ambiguous, use doing first with a bounded, reversible experiment.
- If risk, cost, or strategic disruption is high, use staged approval with explicit go/no-go gates.
- If the initiative is within discretion and a safe test can produce evidence, a bounded renegade experiment may precede formal approval.
- If adoption is the barrier, prefer education, participation, facilitation, and support before negotiation or coercion.

## Readiness and Recipients

- If the readiness questionnaire is below 10, do not assume urgency will create action; strengthen trust, capability, middle-management involvement, communication, and systems thinking.
- If a recipient asks questions, diagnose ambivalence and sense-making before labeling resistance.
- If ADKAR stalls, supply the missing condition: Awareness, Desire, Knowledge, Ability, or Reinforcement.
- If a change alters security, status, autonomy, rewards, or obligations, explain the psychological-contract change and test procedural and distributive fairness.
- If the organizational case is persuasive but an individual remains opposed, calculate that person's perceived dissatisfaction x benefits x probability of success against perceived cost.
- If words, leader behavior, systems, incentives, and deadlines disagree, trust the signal stack: the system people experience usually wins.

## Structure, Power, and Culture

- If uncertainty rises, either reduce information-processing demand with buffers/self-contained work or increase capacity with lateral links, teams, networks, and decision rules.
- If the chart does not explain action, map positional, network, knowledge, reputation, process, resource, and meaning power.
- If a stated value is not lived, inspect Schein's artifacts, espoused values, and underlying assumptions.
- If resistance is strong, reduce a central restraint or change a leverage relationship before simply adding pressure.
- If specialization creates silos, add integration; if coordination costs dominate, reduce unnecessary differentiation or interdependence.
- Formal approval opens the gate. Acceptance requires ownership, time, training, resources, aligned measures, rewards, and visible use.

## Measurement Rules

- Measure from inception through institutionalization; do not wait for the final audit.
- Use leading indicators for movement and lagging indicators for realized outcomes.
- If one metric improves while quality, trust, capability, or customer outcomes worsen, stop optimizing the local target and redraw the causal chain.
- Use Simon's interactive, boundary, belief, and diagnostic/steering controls together.
- Use a strategy map to expose assumptions and a balanced scorecard to prevent one-metric blindness.
- Risk Exposure 9-20 is a safety zone, 21-34 caution, and 35-45 danger. DICE 7-14 is favorable, 15-17 is a worry zone, and 17 is an escalation point.
- If data are being shaded or gamed, reduce punitive pressure, involve users in measure design, and restore legitimacy and psychological safety.

## Fast Smells

- Vision on the wall, old rewards in the workflow: the old culture will win.
- Training complete, outcomes unchanged: activity was measured instead of adoption or effect.
- Executive sponsor ready, recipients not ready: unfreeze the relevant system, not just the top.
- Approval secured, no owner or capacity: the change is optional in practice.
- One hero carries diagnosis, influence, and implementation: build a team and distribute ownership.
- “Everyone must agree” in a complex change: build a credible critical mass, protect dissent, and distinguish nonparticipation from sabotage.
