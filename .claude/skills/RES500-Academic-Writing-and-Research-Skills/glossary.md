# Glossary

**Accuracy** - Low bias or systematic variance in a sample or measure (Ch 5).

**Actionable insight** - An insight tied to a specific decision and capable of guiding action (Ch 16).

**Alpha** - Planned probability of a Type I error when rejecting a true null hypothesis (Ch 14).

**Audience-centric planning** - Designing a report around what the audience should think, feel, and do (Ch 16).

**Automatic Interaction Detection (AID)** - Recursive splitting that finds predictors producing useful subgroup differences; exploratory, not causal proof (Ch 13, Ch 17).

**Case** - One entity, event, record, object, setting, or text unit from which variables are measured (Ch 2, Ch 5).

**Case study** - Context-rich analysis of one or a few cases using multiple evidence sources (Ch 4, Ch 6).

**Codebook** - The documented mapping of variable names, locations, codes, labels, and types used to build a consistent data file (Ch 13).

**Construct** - An abstract idea invented for a research or theory-building purpose (Ch 1, Ch 10).

**Correlation** - Symmetric measure of the direction and strength of association; it does not establish causation (Ch 15).

**Cross-tabulation** - A table that compares categories through cells, marginals, counts, and directed percentages (Ch 13).

**Data saturation** - The point in qualitative collection at which additional cases are unlikely to add new insight (Ch 6).

**Decision rule** - An explicit criterion for choosing among action options (Ch 3).

**Dependent variable (DV)** - The measured outcome presumed to respond to an independent variable (Ch 1, Ch 8).

**Exploratory data analysis (EDA)** - Flexible visual and numerical examination used to find patterns, errors, and useful follow-up questions (Ch 13).

**External validity** - The extent to which a relationship generalizes across people, settings, and times (Ch 8).

**Independent variable (IV)** - The presumed cause or manipulated condition in a relationship (Ch 1, Ch 8).

**Instrument** - A sequenced communication tool containing questions, instructions, transitions, and other data-collection elements (Ch 12).

**Internal validity** - The credibility that the treatment, rather than an extraneous factor, produced an observed change (Ch 8).

**Measurement scale** - A mapping system: nominal classifies, ordinal orders, interval adds equal distance, and ratio adds a meaningful zero (Ch 10).

**Missing completely at random (MCAR)** - Missingness unrelated to the missing or recorded variables (Ch 13).

**Nonresponse error** - Distortion caused by systematic differences between selected participants and nonparticipants or missing items (Ch 5, Ch 9).

**Operational definition** - Observable criteria and procedures that make a construct measurable and reproducible (Ch 1, Ch 10).

**p value** - Probability, assuming H0 is true, of a result at least as extreme as the observed result (Ch 14).

**Population parameter** - A summary descriptor of a target population, such as a mean, variance, or proportion (Ch 5).

**Power** - Probability of correctly rejecting a false null hypothesis; `1 - beta` (Ch 14).

**Reliability** - Freedom from random or unstable error and consistency across repeated, parallel, or rated measurement (Ch 10).

**Research design** - A time-based procedural blueprint for answering the research question (Ch 4).

**Research question hierarchy** - The chain from management dilemma through management, research, investigative, and measurement questions (Ch 3, Ch 17).

**Sample frame** - The operational list from which cases are selected; omissions or extra cases create coverage problems (Ch 5).

**Sampling error** - Difference between a sample estimate and the population value caused by chance selection (Ch 5).

**Systematic sampling** - Selection from an ordered frame using a random start and a fixed skip interval (Ch 5, Ch 17).

**Target population** - The complete set of entities to which the study intends to refer (Ch 5).

**Triangulation** - Combining methods or data types to use complementary strengths and test interpretations (Ch 6, Ch 17).

**Validity** - The extent to which a measure captures what the investigative question requires (Ch 10).
